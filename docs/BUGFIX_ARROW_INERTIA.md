# 跨平台箭头与拖动释放惯性修复

日期：2026-11-08（America/Toronto）。范围仅为两个局部 Bug Fix。

## 根因与修复

### 箭头

原实现是 U+2198 字符，指定 `Arial, Helvetica, sans-serif`。macOS 的实际字体探测表明 Arial 缺字时回退到 Lucida Grande；在不同系统中，字体回退也可能选择 Emoji 字形。仅指定 font-family 不能固定该字符的绘制方式。

替换为内联 SVG，使用 macOS 原字形的轮廓坐标，而非换用另一款图标。112px 字号下原字形进宽为 112，轮廓边界约 80.9375×80.9375，原行框高 100.8，基线 89；SVG 按这些值固定 viewBox、轮廓与变换。外框维持 `1em × .9em`，沿用原字号、定位、hover / active transform、按钮和标签。填充使用 `currentColor`，不依赖系统字体。SVG 对辅助技术隐藏且不可聚焦，原按钮仍有独立 aria-label。

本地内置浏览器替换前后实测：箭头均为 112×100.796875 CSS px；按钮均为 112×123.796875，x=1136、y=568.203125（1280×720 视口）。Safari 文字标签的正常行高可能与其他浏览器不同，因此回归测试在各浏览器中直接创建原字符参照按钮比较，不跨浏览器硬套标签行高。

### 拖动释放

原 `World.release` 只对拖动控制器当时的速度做上限限制。控制器接近目标后速度会下降；若最后一次物理更新较早或拖动停顿，松手时就可能几乎没有惯性。事件层未使用用户近期轨迹来估计速度。

新增无 DOM 的 `DragVelocity`：保存有上限的最近轨迹，使用 PointerEvent 的 client 坐标与同一时钟的 timeStamp，以最近 100ms 的最小二乘斜率估计 CSS px/s。支持可用时的 coalesced events，也兼容不提供该 API 的 Safari。时间倒退、无效坐标、过长间隔、停住后释放或不足的样本时段均不生成异常甩动。

仅在确实发生拖动的 pointerup 中把估计速度交给原 World。保留固定步长、质量差异、弹性碰撞、边界反弹、默认阻尼和原有 rAF 调度。释放附加阻尼同样在原物理步中执行，没有第二个动画系统。

集中参数位于 `assets/config.js`：

| 参数 | 当前值 |
|---|---|
| 轨迹窗口 / 最大间隔 / 过期释放 | 100ms / 80ms / 80ms |
| 样本上限 / 最小时段 | 24 / 8ms |
| 释放速度倍率 / 上限 | 0.9 / 170 CSS px/s |
| 释放附加阻尼 / 持续时间 | 0.9 s⁻¹ / 2.2s |
| 原默认阻尼 / 自由速度上限 | 0.16 s⁻¹ / 180 CSS px/s，保持不变 |

慢拖与快甩的初速度不同，快甩受向量限速；附加阻尼在短时内消退高速状态，随后回到原有漂浮。静止点击不再调用释放逻辑。pointercancel、丢失 capture、窗口 blur / 页面隐藏均取消当前拖动，不生成释放甩动；取消不会将其他圆圈速度一起清零。reduced-motion 关闭释放惯性。拖动后的点击抑制沿用原阈值和时长，也覆盖取消路径。

## 回归覆盖

保留原 41 项验收，并增加 19 项针对性测试（共 60 项）：

- 8 / 16 / 32ms 事件频率下速度单位与方向一致；最近反向轨迹、静止、过期、重复时间戳、异常间隔与无效值。
- 控制器速度为零时仍能应用轨迹甩速；快慢力度、释放速度上限、继续运动与自然衰减。
- 惯性碰撞与边界反弹；30 次连续多方向高速输入后的限速、分隔与边界稳定。
- 鼠标 / touch / pen 事件经真实首页模块的确定性 rAF 夹具，验证释放后继续沿轨迹移动且不误触搜索。
- 停住再释放、pointercancel、blur、reduced-motion 与静止点击不会产生意外甩动。
- SVG 固定几何、独立按钮名称、currentColor 浅深色、SVG 点击与键盘式按钮激活。
- 390×844、1024×768、844×390 尺寸下，与原字符按钮的位置及点击区域直接比较。

测试夹具只存在于 `tests/`，使用实际首页及模块；没有向生产页面加入调试开关。测试中的 touch / pen 事件是合成输入，不代表触屏或触控笔硬件实测。

## 设备验证边界

macOS Safari 27.2、Chrome 156.0.8078.81 与内置浏览器已实际运行完整套件，各 **60 项通过 / 0 项失败**。macOS Safari 另实际打开首页检查 SVG 轮廓，并执行鼠标拖动，未误触搜索。详细执行状态同步记录在 PROJECT_STATUS.md。iOS Safari、iPadOS Safari 和触控板/触屏硬件均须明确区分：SVG 不含可被转换为 Emoji 的文字是代码与浏览器回归结论，不能据此将 iPhone 或 iPad 真机标记为通过。

关键词 JSON、管理页面、数据模块、搜索抽样和 URL 编码、布局生成器均未修改；没有更换配色、字体系统或整体布局，没有进入第二阶段。
