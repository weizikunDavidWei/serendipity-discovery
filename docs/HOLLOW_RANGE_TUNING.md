# 切向影响范围调整 · 2026-11-09

当前控制项是影响范围，按此语义将最大物理外延减半：extent = R × 0.5 × (0.35 + 2.65 × slider)。滑块仍为0–100%，100%外延由3R降至1.5R；0%仍完全无影响。固定coreRatio=.18，不改变切向贴弧/压缩强度、地形层级或动画速度。

公开默认及离线fallback的hollowSize=.01；管理页初始显示1%。独立「恢复默认」改为读取公开默认配置，统一恢复默认也使用1%。既有个人设置优先，未强制抹去已保存的用户选择；已有用户可在后台点恢复默认回到1%。本地设置没有被当作公开配置。

Chrome真实WebGL交互15项通过，包含新用户GPU默认1%、后台初始1%、恢复默认1%、开关与动态跟踪。方向/压缩24项通过；远场像素检查特意在100%最大设置验证超出1.5R外延处没有变化。Safari/Edge和实体触屏本轮未实测。
