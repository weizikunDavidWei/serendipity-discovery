# 首页视觉与物理交互迭代 · 实际验收

日期：2026-11-08（America/Toronto）。这是第一阶段现有网站的设计迭代，没有扩充词库或进入第二阶段。

## 视觉与交互变化

删除原大标题、Hero 说明、栏目标签、分隔线、底部信息条和固定网格。改为完整视口的黑白几何空间，边缘只保留 SERENDIPITY™、重新随机、管理入口和少量操作提示。大型 ↘ 保留并成为完全随机探索入口。

每次抽取桌面 5–9 个不同主题，尺寸与位置也重新组合。较小视口通常 5–6 个，极端分屏空间不足时允许继续减少。放置算法混合邻近聚集与开放区域采样，没有隐藏的网格。桌面 1440×900 的测试中，最大圆直径至少 350px，大小比超过 2.4。

物理参数集中于 `assets/config.js`。布局、无 DOM 的物理求解与页面调度分别独立。固定时间步 1/120 秒，质量随面积变化；具备速度冲量、恢复系数、接触分离、边界反弹、阻尼、限速及微弱低频驱动力。拖动通过目标速度推进，释放保留有限惯性；后台暂停，减少动态效果下保持静态，键盘聚焦时暂停漂移。

## 41 项验收覆盖

- 5、7、9 圆圈，各 20 个固定随机种子：数量正确，巨大与小圆同屏，保持间隙与控件避让。另用 `tests/preview.html` 装载真实首页分别核查 5 / 7 / 9 圈和深色场景。
- 390×844、320×568、768×1024、844×390，各 10 个随机种子：5 圈可布置，无强制重叠。
- 面积质量测试：大圆撞小圆后，小圆速度更明显；无风、无阻尼、完全弹性测试中的线性动量守恒。
- 同尺寸圆碰撞速度对称，恢复系数有效。
- 同心和密集初始状态可稳定分离，没有 NaN 或持续重叠。
- 快速拖动大圆穿越小圆群、链式传递、释放速度上限及连续位移检查。
- 拖向边角控件仍保持在视口边界；9 圈共 36,000 步，每秒抽检分隔、边界和有限数值，最终数量和速度保持有界。
- 30 / 60 / 120Hz 输入的十秒轨迹一致；大时间差只执行有限步数。
- 真实首页 1440 → 390 → 1440 尺寸变化后恢复有效布局；320 / 390 / 768px 页面无水平溢出。
- 浅深色规则切换后的颜色正确；首页含 ™ 与大型 ↘，旧 Hero 和 grid 不存在。
- 正常点击同步生成正确编码的中文 URL，近期去重和完全随机保留。
- 模拟 mouse / touch：小幅移动后可点击，明显拖动后的 click 被抑制，键盘式激活不受拖动抑制影响。
- reduced-motion 媒体事件：真正停下模拟，取消后恢复，再开启后停下；模拟页面隐藏事件停止运动，恢复后边界仍有效。
- 重复换组 12 次，DOM 圆圈数量有界，页面无滚动条。
- 全部原数据校验、CSV 安全往返、主题和关键词增改删、批量去重、搜索统计、草稿刷新恢复、JSON/CSV 导入导出、备份恢复及管理页手机布局回归。

## 额外真实操作

Safari 实际打开首页并显示八个不同尺寸圆圈；使用鼠标连续拖动巨大圆圈，观察其他圆圈位移与分离，未跳转搜索。随后正常点击“风味地图”，确实在新标签页打开中文搜索“乳酸菌发酵”。内置浏览器使用 Enter 激活主题，状态区显示对应中文探索词。

Safari 首轮动态恢复检查失败时，测试 iframe 位于屏幕外。将测试 iframe 滚动至可见区域后重新执行，41 项全部通过。没有为通过测试而放开生产页面的后台暂停逻辑。浅深色与 reduced-motion 的自动检查通过测试专用 iframe 修改媒体规则/模拟媒体事件；没有擅自修改用户操作系统偏好。

## 边界与已知限制

- 未进行数小时的堆内存剖析。已确认重复换组后的 DOM 数量有界、近期历史上限 20、世界对象上限 9、单一动画调度；这不等同于证明所有环境永不发生内存泄漏。
- 极小、极短窗口可以减少圆圈数；常规手机已验证仍可展示 5 圈。调整窗口时短暂过渡可能让物体在视觉上相交，过渡结束后的物理状态不持续重叠。
- 圆圈和箭头保持系统黑白模式；管理页保留原独立工作台布局，只将品牌标识同步改为 ™。
- 不控制 Bilibili 服务内容或第三方浏览器弹窗策略。

## 重复验证

项目目录启动 `python3 -m http.server 8767 --bind 127.0.0.1`，访问 `http://127.0.0.1:8767/tests/` 并运行。使用独立测试来源，保持动画采样页可见；测试会临时修改并恢复该来源本地草稿。`tests/preview.html` 可核查具体圆圈数量与颜色，但产品首页没有测试控制台。
