# 空洞扭曲方向修正 · 2026-11-08

2026-11-09更新：当前外延已减半、默认1%，见 [范围调整](HOLLOW_RANGE_TUNING.md)。下述数值验收保留为方向修正当日记录。

## 根因及最终效果

旧实现对噪声采样点做正向径向平移。虽然画面有变化，它没有约束等值线在球缘的方向，主要表现为径向拉扯；原测试仅验证像素改变与源跟随，不能检出这个方向错误。

本次改为极坐标核区映射。对球外可见点，原半径 d 映射到采样半径：

```
rho = sqrt(d*d - R*R + (0.18*R)^2)
```

角度不变。在球边，采样半径约0.18R，径向导数约5.56；角向采样尺度约0.18。这个不等向映射放大径向地形斜率、压缩角向变化，结果是**现有等值线的切线沿圆周延展**、靠近边缘的线距缩小。没有旋转角度、添加圆形等值函数或独立绘制圆环。仍然只采样原Topolines噪声、原等值层级，动画/颜色/透明度不变。

原滑块继续只控制外部影响支持范围 R*(0.35+2.65*size)，0%与OFF继续直通原地形。0.18核区比例固定，不随滑块改变。smoothstep 将映射混回原坐标，边缘处连续衰减。邻球用连续、与顺序无关的归一化权重混合，避免无界叠加、最近球切换造成的接缝。球内部数值有界，视觉被原实体球遮挡。

生产代码只修改 assets/vendor/topolines-0.3.0.js 的采样映射和注释。几何源、物理、管理页面/设置、JSON默认值、准星、搜索及CSS均未改动。保留单画布、原有启停和reduced-motion策略。

## 实际验收

安装版Chrome headless，运行真实WebGL与原生页面：

- 新增 tests/hollow-direction.cjs + hollow-direction.html：**24项通过**。24项包含方向/压缩的16项（半径205px与84px、4个固定种子）和远场、范围、叠加、移动等8项检查。
- 方向测试只在测试上下文替换最终像素输出，读取生产标量场的GPU导数，而不改变采样逻辑。梯度越接近径向，等值线切线越接近圆周切线；近边缘采样带为1.015–1.12倍半径，4圈×192点。径向梯度对齐平均值由关闭时0.488–0.729升至0.896–0.957；平均径向斜率为原来的2.43–4.58倍，支持方向与局部线距压缩。仅代表这些受控场景，不是所有地形和球体的普遍数值保证。
- 将3020589旧版Shader通过测试路由注入，同一方向测试**如预期失败**，证明不是只检查有无视觉变化。测试输出另存为旧版基准记录。
- 正常线条像素（不是诊断输出）验收：远处超出影响范围的像素变化0；球缘带改变22729像素；OFF和0%像素差0。保持原有地形，而非叠加装饰图案。
- 三个邻近大小球，最小可见间距8px：改变源顺序最大仅2/255 alpha差（浮点累加精度），无明显接缝。移动大球24步、每步0.25px，逐帧全图平均alpha变化最大0.664/255，没有大幅跳变；无GL错误、只有1个画布。该检查不替代无限时长、所有位置的视觉保证。
- 人工检查同一固定地形ON/OFF、大小球分离、三球贴近和实际随机首页的截图，确认贴合圆弧及压紧效果，而非放射状指向圆心；还检查了深色画面。
- 原空间扭曲14项、Topolines21项、Crosshair10项全通过。含真实鼠标拖动后的源跟随、开关/0%/滑块即时更新与刷新保存、黑白模式和搜索。完整旧62项回归仍54通过/8个相同旧词库基准失败，不将其标为通过。
- 本机120帧rAF样本中位16.7ms；关闭时100ms内球体几何读取0。此为短时观测，不是跨设备性能或长期内存保证。390px管理页/首页布局模拟无溢出。

Safari、Edge、iOS/iPadOS和触控硬件本轮未实测；手机仅Chrome视口模拟。没有声称肉眼或数据覆盖所有浏览器、硬件和任意地形。

## 复跑

在项目根目录启动本地静态服务（默认8765），用有Playwright与Chrome的Node执行：

```
node tests/hollow-direction.cjs
node tests/hollow.cjs
node tests/topolines.cjs
node tests/crosshair.cjs
```

可用 PLAYWRIGHT_MODULE 指定Playwright安装路径，TEST_URL指定测试站点。BASELINE_SHADER可指定旧版vendor文件，检验旧版本是否被方向回归拒绝。测试夹具不是首页功能或独立产品设置页。
