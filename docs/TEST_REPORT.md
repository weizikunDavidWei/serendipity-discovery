## 方法与边界

浅深色测试在同源 iframe 中切换应用原有 CSS 媒体规则，等待 300ms 颜色过渡结束后读取计算样式。首次验收有 2 个失败，原因是测试即时读取过渡颜色，以及修改媒体条件后无法再次找到原规则。修正测试对原规则的引用和等待时机后，全套复测通过；生产页面仍仅通过 prefers-color-scheme 跟随系统，没有测试专用主题开关。

响应式检查使用具有实际 CSS 宽度的 iframe，检查文档 scrollWidth 和每个圆圈的 boundingClientRect、宽高及文字溢出。当前内置浏览器的顶部视口覆盖并不可靠，因此尺寸验收以 iframe 内的真实宽度为准。

测试结束恢复之前的本地存储。测试页面应在独立端口运行，避免与正在编辑的管理页共享来源。可在测试页面查看逐项 PASS/FAIL。

尚未执行独立 Safari、Chrome、Edge、手机真机及辅助技术实机测试。键盘交互使用原生 button / form / link 与 focus-visible；reduced-motion 已实际读取计算样式确认。不能据此声称所有浏览器均实机通过。
