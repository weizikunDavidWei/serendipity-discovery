# 物理输入链路与碰撞手感重构

日期：2026-11-08（America/Toronto）。范围仅为物理交互，不扩词或重做设计。

## 此前为什么数值测试通过，实际手感仍不理想

1. 原释放上限 170px/s，碰撞后统一限制在 180px/s；即使大圆把明显更大的速度传给小圆，也会立即被削平。与直径 350–500px 的物体相比，速度与自由滑行距离不足。
2. 释放后额外施加 0.9s⁻¹ 阻尼持续 2.2s，使刚释放的大圆很快丧失足够的撞击速度。
3. 本次真实 Safari 指针自动化记录显示：一次大幅快速移动与松手的时间戳相同，整个有效段只有约 1ms。旧估计器要求至少 8ms，直接返回零。此前构造的时间戳始终间隔 20ms，漏掉了这个实际输入路径。
4. 页面用 `:focus-visible` 决定是否停止模拟，未区分指针与键盘来源，存在把指针后的焦点误当作键盘暂停的风险。现在使用显式输入模式。

这次没有引入第二个物理引擎。圆形冲量求解器仍适合最多九个圆；主要重整输入控制器、速度预算、阻尼和验收方式。

## 实现

- `assets/interaction.js` 抽出唯一的 Pointer Events 控制器，供首页和真实输入验收场景共同使用。管理 Pointer Capture、点击/拖动分流、结束与取消。首页仍只用一个 rAF 和一个固定步 World。
- 轨迹保留同时间戳的不同位置；短于 8ms 的有效移动用最短估计时段求端点速度，再由 World 向量限速。重复的 pointerup 坐标不被误当作停顿；长时间停住、时钟异常、取消和失焦仍不产生异常甩动。
- 指针操作明确唤醒模拟。只有 Tab/方向键导航后进入圆圈的键盘焦点才暂停；指针松手后不会仅因 focus-visible 而停下。
- 移除专门压制释放运动的计时阻尼，改为连续的速度相关阻力。低于 40px/s 时保持原漂浮阻尼，高速时平滑增加阻力。碰撞后的运动也服从同一规则，没有独立释放动画。
- 面积质量、固定 1/120 秒步长、十二轮接触分离和可见间隙保留。放宽速度预算，让较小圆圈实际呈现更明显的撞击反应。

集中参数：自由速度上限 1100、拖动上限 1400、释放上限 720 CSS px/s，释放倍率 1；恢复系数 0.88，边界恢复系数 0.76；默认阻尼 0.16s⁻¹，速度相关阻尼系数 0.55，阈值 40px/s；拖动质量倍率 2.2。参数均在 `assets/config.js`。

## 实际交互验收

### 核心：真实输入释放后撞开三个小圆

在 macOS Safari 中打开 `tests/throw.html`，通过原生鼠标自动化执行真实、受信任的 pointerdown / move / up，没有用脚本直接设置世界速度或位置。验收页复用生产 World 和 bindDrag，只记录测量值。

- 初次复现：移动与释放集中于同一毫秒，释放速度为零，未通过。
- 修复稀疏事件估计后：释放速度 **720px/s**；松手后最大滑行 **737px**；三个小圆最大位移分别约 **242 / 218 / 179px**；误搜索 **0**。
- 判据：必须在真实 pointerup 后继续滑行超过 150px，并使三个小圆各移动超过 45px；显示 **PASS**。位移统计保留反弹前最大值，避免碰撞返回原处掩盖已发生的响应。

### 真实首页，而非仅独立物理场景

`tests/home-input.html` 用 iframe 装载未改写状态的实际首页，只观察 DOM 位移。Safari 实际拖动大圆后，真实 pointerup 后约 **522ms** 最大位移 **158.7px**，显示 **PASS**。没有操纵世界状态或时钟。确认首页输入/焦点调度不会吞掉释放后的运动。

上述输入来自原生自动化鼠标事件，不代表触控板或手机硬件验收；与人工触感偏好仍有区别，但完整经过了浏览器真实事件、生产输入控制器、物理更新和绘制。

## 自动回归

macOS Safari：**62 项通过 / 0 项失败**。

- 保留原测试，新增同毫秒 / 1ms 快速移动与释放后三圆连锁的回归。
- 更新衰减判据，要求存在有用的滑行距离，并在后续自然降速；不再用旧的过强阻尼作为正确性标准。
- 碰撞动量测试显式关闭全部阻力，以免把设计中的速度相关阻力误当作动量计算错误。
- 真实首页的事件夹具在 pointerup 后补发焦点事件，确保指针不会被焦点暂停。
- 修正搜索测试的状态隔离：箭头测试已随机探索过两个词条，可能占用待测主题的近期历史；测试现在从全新页面验证完整主题周期。搜索实现未修改。
- 保留五分钟物理时间稳定性、多个视口、连续甩动、点击/拖动、mouse/touch/pen 合成事件、reduced-motion、SVG、数据校验和管理系统回归。

五分钟为加速模拟，不是五分钟人工录屏；未执行数小时内存分析。独立 Chrome / Edge、iOS / iPadOS、触控板和触屏硬件本轮未实测，不沿用旧版本的通过结果。为避免无限扩展环境覆盖，本轮以 Safari 实际交互和完整回归为主要验收。
