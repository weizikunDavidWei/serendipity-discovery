# 粗体与视口坐标 · 2026-11-08

默认字重改为800、品牌900，沿用原生系统中文与西文字体，强调黑白几何和工业标识感；没有使用或宣称复制游戏专有字体/资产。后台视觉设置新增「字体力度」：细字体恢复全部原始样式，粗字体使用新规则；个人设置 fontWeight 位于既有 serendipity.visual.preferences.v1。新公开默认 fontWeight:bold；旧个人设置缺失字段自动补默认。支持跨标签页、刷新和恢复默认。关键词和物理代码不改动。

准星边缘读数：左端为Y，下端为X；视口左下角(0,0)，右上角(width,height)。计算用CSS视口像素：X=clientX，Y=innerHeight-clientY；不是显示器硬件物理像素，因此不乘devicePixelRatio，浏览器缩放及系统高DPI不会混用坐标单位。跟随平滑十字线位置；限定标签始终在视口内。无固定坐标轴额外装饰、无圆球直径标签。关闭、触摸、reduced-motion与原准星同样隐藏并停止；只读取几何，不处理点击/拖动。

Chrome实际网页15项测试通过：默认粗体、左下/中心/右上数学值、1440×1000、3840×2160、800×600下的读数与边界，后台切换细体/粗体、跨标签页同步及刷新持久化、关闭/减少动态效果隐藏读数、390px首页与管理页无溢出。截图人工检查。等高线21项回归通过。原完整回归与准星回归结果见本次输出；旧套件8项历史词库基准失败未修订。

本轮Safari/Edge及真实触屏/4K显示器硬件未实测；3840×2160为Chrome视口模拟。字体是当前平台实际安装字体的加粗版本，平台字形差异仍存在。

测试：本地服务运行后使用含Playwright与Chrome的Node执行 tests/typography-coordinates.cjs；支持 PLAYWRIGHT_MODULE 和 TEST_URL。
