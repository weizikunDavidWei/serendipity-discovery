# 搜索平台完整验收（2026-11-09）

上一版本已提供五个平台选择。本轮按补充验收要求检查原实现，保留三槽结构、独立模式/服务ID及原有个人设置，并发现、修复了一个Safari实际兼容问题。

## 实际修改

- 后台标题明确为「搜索平台」，选择后立即保存，无额外保存操作。
- Safari原生控制台曾显示`Importing binding name 'isBrowserProvider' is not found`：新后台引用了缓存中的旧搜索模块。为搜索入口及相互依赖统一加版本查询，普通刷新即可加载兼容的模块组合，不需清除草稿或偏好。
- 前后台仍复用原storage事件和存储键。页面从缓存恢复或重新可见时重读模式及服务，保持标签、选中槽位和真实搜索目标一致，不重建场景。
- 不修改关键词、物理、SVG、准星、等高线、扭曲场、Slide Commit或主页样式。
