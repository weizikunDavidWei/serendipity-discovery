# 空洞彩蛋与新艾利都世界重置（2026-11-09）

本轮检查时仓库只有Hollow背景扭曲，没有空白球生成系统。因此先实现附件所述基础彩蛋，再增加世界重置结局。没有新增前台控件或修改关键词数据库。

## 规则与事件状态

默认在首页空白区域用鼠标/触控板主键完成5次点击，相邻间隔不超过500ms，生成一个无文字球体。仅pointerup计数，拖动、按住超过500ms、控件/球体交互、键盘、失焦及页面隐藏清除未完成计数。触摸背景点击不冒充鼠标；生成后的空洞支持触摸拖动。

当前物理世界的egg对象是唯一数量来源，上限30，不计入主题或后台关键词统计。普通刷新恢复球体、正常主题和必要物理状态，不重播所有生长动画；平台切换不清理球体。

独立`worldResetPendingExploration`用于结局：

- Slide Commit成功提交时旧世界有至少7个彩蛋：清空彩蛋、生成原有正常主题、清空连击，启用标记。
- 少于7个按原规则重置；半程、取消、失败不启用结局、不丢旧场景。
- 标记独立存入原sessionStorage记录，零彩蛋仍显示「世界已重置，欢迎来到新艾利都。」；刷新保留。
- 只有正常主题球的搜索成功发起才清除。空白点击/拖动、球体拖动及完全随机探索均不清除。
- 在结局期间新建空洞，清除旧结局标记，由新的灾害播报接管。可反复完成结局。
- 对结局中的主题搜索，先在可信点击内创建空标签页以判断弹窗是否接受，再断开opener，并用noreferrer/no-referrer链接导航。被拦截时保留结局。普通搜索仍走原同步路径与适配器。已实测真实弹窗、无opener与无Referer。

## 实现

- `egg-input.js`负责唯一计数入口；`egg-settings.js`管理个人设置及按球体数选择的15个播报节点。
- `egg-geometry.js`寻找点击附近的可用空间，预留最终半径；World固定步中以460ms克制ease-out-back曲线改变实际半径，DOM、质量与扭曲源使用同一半径。没有第二套漂浮/碰撞动画。
- 原World复用全部拖动、惯性、质量、边界和碰撞，只加入可选生长及远距碰撞快速排除。
- 原Topolines单Shader容量扩至39源（9主题＋30彩蛋），远处片元快速跳过。正常帧从物理模型读取几何，避免每帧读取39个DOM框；窗口过渡使用显示几何。16个及以上彩蛋时背景DPR上限0.9，重置后恢复，种子和时钟不重置。背景关闭、隐藏、reduced-motion沿用原机制。
- 左下角复用原提示，95ms淡出、200ms非线性淡入；连续更新只保留最新文本。reduced-motion静态替换。移动长文案最多5行，完整文本仍可读屏/查看标题，不盖住底部控件。

附件未提供中间节点原文。首条、终极30条及结局使用指定原文；其余中间播报为本轮原创，可编辑。

## 后台开发者模式

管理页展开「开发者模式」，启用编辑后可以：

- 关闭/开启连续点击生成；关闭不删除已有球体。
- 设置任意正整数次数，最低1，不设置业务上限，使用字符串和BigInt比较避免浮点精度丢失。
- 选择1、2、3、5、7、10、12、15、18、20、23、25、28、29、30或世界重置节点，编辑文案；最多300字符，纯文本呈现。
- 恢复默认5次及全部默认文案。

个人偏好仅在当前浏览器localStorage保存，同源标签页同步，不修改其他访客默认、词库或GitHub数据。30球上限与7球结局阈值保持固定。未列出的数量沿用最近达到的播报。

## 实际验收

- Chrome核心38项通过：4/5点击、间隔/排除、6/7/30重置、半程/失败、独立结局、刷新、真实弹窗/拦截、随机探索不结束、主题拖动不结束、新空洞接管、重复触发、开发者次数/关闭/自定义结局/持久化/文本注入、动态半径、移动布局与触摸。
- 满载6项通过：9主题＋30彩蛋共39对象、39个Shader源、接触/速度/边界、拖动、reduced-motion、390×844恢复30个且无穿透。
- 本机180帧样本：中位16.7ms、P95约16.8ms；1200固定步约105ms，最大穿透0px。单Canvas、对象数量有界。不是跨设备帧率保证，未作长时堆快照分析。
- macOS Safari原生：后台把次数改为1用于测试；实际生成7个，鼠标拖满右上滑轨，观察指定结局；Cmd-R仍保留，点击主题打开新标签后原页面恢复提示；测试后恢复默认5次。已查看深色完整页面。默认5次及30满载由Chrome覆盖。
- 既有专项回归186项通过：平台35、跟手13、Hollow15、方向24、Topolines21、Slide22、准星10、浏览器配置46。旧通用套件仍54通过/8个原有词库数量及管理链式断言失败，未改词库以迁就旧基准。部分首次本地启动超时，单独重跑完成，未把超时记为通过。
- Edge、实体iOS/iPadOS/触屏、独立触控板硬件及高刷新率硬件本轮未实测；移动触摸为Chrome CDP模拟。

结构化结果见`EASTER_EGG_RESULTS.json`和`EASTER_EGG_REGRESSION.txt`。本地服务上运行`tests/easter-eggs.cjs`、`tests/egg-performance.cjs`；依赖与原有Playwright/Chrome测试相同。可用`TEST_URL`对正式站点复测，测试仅使用隔离浏览器的个人和会话存储。
